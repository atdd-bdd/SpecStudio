
SpecStudio is an IDE that allows teams to collaborate on specifications 

It should appear similar to Visual Studio and other IDEs.  

It should use Qt, so that it works on all platforms 

A solution is a just a container for related projects. When creating a new project, it can 
	go into existing solution or a new one.  A solution has a root folder. 

A Project represents the specifications for a project. It has a root folder, contained
	in the solution folder.   Each project has its own git.   
  
The project folder may have sub-folders.  The files in each folder may be:
	Feature Files (.feature)
	Feature Extended Files (.featurex)
	Excel Files (.csv, .xls, .xlsx) 
	Markdown Files (.md) 
	Text (.txt) 
	Other - none of the above 

The initial version will have native editors for .feature, .featurex, and .txt files 

Settings (1)
	Set the editors for files, based on the extenions.
